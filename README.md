# Fishmodoro

Un timer pomodoro nel browser: ogni minuto di concentrazione si trasforma in crediti
con cui comprare pesci in pixel art per il tuo acquario. Più ti concentri, più la vasca si popola.

## Comandi

- `npm install`: installa le dipendenze
- `npm run dev`: avvia il server di sviluppo
- `npm run build`: compila per la produzione
- `npm run preview`: serve la build compilata
- `npm run lint`: controlla il codice
- `npm run typecheck`: controlla i tipi
- `npm test`: esegue i test (`npm run test:watch` per la modalità interattiva)
